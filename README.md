# Frank Zhang Personal Homepage

这是张暄奇（Frank Zhang）的个人学术主页静态版本，可直接部署到 GitHub Pages。

## 部署

1. 新建或打开仓库 `kk77-Frank.github.io`。
2. 将本文件夹中的 `index.html`、`styles.css`、`script.js`、`assets/` 上传到仓库根目录。
3. 在仓库 Settings -> Pages 中选择 `Deploy from a branch`，分支选择 `main`，目录选择 `/root`。
4. 部署完成后访问 `https://kk77-frank.github.io/`。
